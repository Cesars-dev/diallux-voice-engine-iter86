## How to Use This KB

1. When the customer says their name, retrieve this KB.
2. Check if the spoken name (case-insensitive) has a 100% match in the list below.
3. If 100% match → use the name as-is. Mirror back naturally.
4. If no match → follow `##name-spelling-kb##` for the spelling confirmation flow.

The list is alphabetical. Common British and Indian names found in the UK are included.

## Notes

- This list covers the most common British and Indian names found in the UK.
- It is not exhaustive. If a name is not on this list, it doesn't mean it's wrong — it means the agent should follow `##name-spelling-kb##` to confirm spelling.
- Names are stored as the most common spelling. Variant spellings (e.g. "Katherine" vs "Catherine") may exist — match case-insensitively and use the customer's spoken form.
- For names with multiple common spellings (e.g. "Jon" vs "John"), if the customer's spelling doesn't match but sounds the same, treat as a 100% match and use the customer's spelling.
